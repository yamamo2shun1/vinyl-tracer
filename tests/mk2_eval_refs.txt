# Reference values for tc_analyze --eval on the Traktor MK2 recordings
# (wav/traktor/rec, outside the repository). Fixed once so that later changes
# of the decoder do not move the reference with it.
#
#   <recording> ref <time s> <position ms> <tolerance ms>   absolute position of the record
#   <recording> drop <time s>                                needle landing (start of the carrier)
#   <recording> still <t0 s> <t1 s>                          record known to be stopped
#   <recording> polarity <+1|-1>                             sign of (L + R) x d(L - R)/dt that is forward on
#                                                            the record (the same for all of these recordings;
#                                                            found from the references, which agree best with -1)
#
# Tolerance 1 ms: the decoder's position has ~0.1 ms latency, and the L - R
#   integration between two references closes within 1-2.3 ms (the closing error is
#   spread over the way when it is within the sum of the two tolerances).
# ref: from tc_analyze of ed7f92b (--csv, 1 row per ms) at moments with the bits
#   verified (code_lock) and anchored for 100 ms, a fresh lock after the last
#   loss of signal, 0.3-2.5x, and no correction from 100 ms before to 300 ms
#   after (a slip can leave verified bits with a wrong position until the
#   correction a few bits later). Consecutive references were then checked
#   against the motion integrated from the phase of L - R (--eval): ones that
#   disagree by more than the sum of the tolerances and have no confirmed
#   neighbour were dropped. The check lines below each recording are the result.
# drop: first 1 ms window of L - R above -40 dBFS after the lift (waveform).
# still: b_not_move / b_not_move_hit stand still for the whole recording (needle
#   on a stopped record; knocks at about 9.5, 11-12, 14.5-15.5 and 24 s in _hit).
# b_needle_up_drop: no carrier at any time (the record was not turning), the
#   decoder never locks: needle drops there cannot be measured.
