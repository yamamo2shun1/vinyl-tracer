01既存の類似プラグインに対する不満を改善

徹底したドリフト対策

速度を積算せず、搬送波の位相と LFSR の絶対位置から、レコードの位置を毎回直接求めます。誤差が溜まらないので、5分間の激しいスクラッチでもドリフトは 0.2 ms 以下。

−0.17 ms 5分後のドリフト

低速域での追従性

ゼロクロスを待たずに、L/R の位相を毎サンプル測って3次 PLL で追従します。レコードが 0.01 倍速で動いていても、音は止まりません。

100 % 0.01x での追従率

CPU 負荷の軽減

解析と再生は依存ライブラリなしの C++17。1デッキ・48 kHz で、解析と再生を合わせて 1 コアの約 0.5 % です。

0.5 % 1コアあたりの負荷

02その他の特徴

キャリブレーションの自動化

DJ ソフトウェアでは必須のタイムコードのキャリブレーションを自動化し、調整を容易にしました。また、L/R の入れ替えや極性の反転にも自動で対応。

キューポイント

DJ でおなじみの機能を搭載。長い音源でも、好きな位置からすぐにスクラッチできます。

オープンソース

ソースコードは GitHub ですべて公開しています。あなたのアイデアを AI とともに実現させることも可能です。

バッファサイズは 64〜128 サンプルがおすすめです（遅延はほぼバッファサイズで決まります）。
