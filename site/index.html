01Fixing the usual pain points

No drift, by design

Instead of adding up speed, Vinyl Tracer reads the record position directly from the carrier phase and the absolute LFSR position every time. Errors never pile up, so even after five minutes of hard scratching, drift stays under 0.2 ms.

−0.17 ms drift after 5 minutes

Tracks the slowest moves

No waiting for zero crossings: the L/R phase is measured on every sample and followed by a third-order PLL. Even with the record moving at 0.01x, the sound never stops.

100 % tracking at 0.01x

Low CPU load

Analysis and playback are plain C++17 with no external libraries. One deck at 48 kHz uses about 0.5 % of a single core for both together.

0.5 % of one CPU core

The plugin window: timecode scope, scrolling waveform, and cue points

02More features

Automatic calibration

Timecode calibration, a must in DJ software, happens automatically, so there is nothing to tweak. Swapped L/R channels and reversed polarity are handled automatically too.

Cue points

The DJ staple, built in. Even in a long sound, jump to any spot and start scratching right away.

Open source

All of the source code is public on GitHub. You can even bring your own ideas to life with the help of AI.

A buffer size of 64–128 samples is recommended (latency is mostly set by the buffer size).
