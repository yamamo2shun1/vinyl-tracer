01既存の類似プラグインに対する不満を改善

徹底したドリフト対策

速度を積算せず、搬送波の位相と LFSR の絶対位置から、レコードの位置を毎回直接求めます。誤差が溜まらないので、5分間の激しいスクラッチでもドリフトは 0.2 ms 以下。

−0.17 ms 5分後のドリフト

低速域での追従性

ゼロクロスを待たずに、L/R の位相を毎サンプル測って3次 PLL で追従します。レコードが 0.01 倍速で動いていても、音は止まりません。

100 % 0.01x での追従率

CPU 負荷の軽減

解析と再生は依存ライブラリなしの C++17。1デッキ・48 kHz で、解析と再生を合わせて 1 コアの約 0.5 % です。

0.5 % 1コアあたりの負荷

  • 配線は自動判定　L/R の入れ替えや極性の反転があっても、8 通りの組み合わせを並行して試して自動でロックします。
  • Absolute / Relative　針の位置＝サンプルの位置にするか、動きだけを使うかを選べます。
  • キューポイント 6 個　好きな位置を登録して、そこから再生できます。
  • 針飛びに強い　針の載せ替え・溝飛びではクロスフェードで位置を移し、クリックを抑えます。

02使い方（Ableton Live の例）

  1. 入力をつなぐ

    オーディオトラックの入力を、ターンテーブルがつながっているチャンネル（ステレオ）にし、モニターを In にします。

  2. プラグインを挿す

    トラックに Vinyl Tracer を挿し、Load Sample... かドラッグ＆ドロップでサンプルを読み込みます。

  3. 面を合わせる

    Timecode を使うレコードの面（Side A / Side B）に合わせます。

  4. レコードを回す

    スコープに円が出て SIGNAL ok / CODE ok / ABS ok になれば準備完了。あとはスクラッチするだけです。

バッファサイズは 64〜128 サンプルがおすすめです（遅延はほぼバッファサイズで決まります）。パラメータとキューの詳しい使い方は README を見てください。
